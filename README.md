# String Art Multiplication Table Canvas

## 概要
円周N点（60〜360）に整数m（2〜99）倍の点へ糸を張るマルチプリケーションアート。m=3でカルジオイド、m=2でネフロイドが出現する数学的ビジュアルアート。

## 機能
- 点数N（60〜360）と乗数m（2〜99）のスライダー
- 線の透明度と色相の調整
- プリセット（カルジオイド/ネフロイド等）
- mを2〜99まで自動アニメーション
- 色相グラデーションによる美しい描画

## 使い方
Nとmのスライダーを動かすと図形がリアルタイムで更新されます。「▶ Animate m」ボタンでmを自動的に変化させながらパターンの変化を観察できます。m=3でカルジオイドが現れます。
